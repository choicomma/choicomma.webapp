# 초이콤마 다이렉트 프린트 브릿지 (Choicomma Direct Print Bridge)

A4 복합기(Canon GX7000)와 CJ 송장 라벨 프린터(Xprinter XP-DT108B LABEL)가 함께 설치된 매장/사무실 메인 PC 전용 다이렉트 인쇄 에이전트입니다.

## 주요 기능
1. **무인쇄창 즉시 출력**: 브라우저 인쇄 설정 창(Ctrl+P 대화상자) 없이 `Xprinter XP-DT108B LABEL`로 0.5초 만에 직접 출력합니다.
2. **프린터 충돌 제로**: 윈도우 기본 프린터가 A4 복합기(Canon GX7000)로 설정되어 있어도, 송장 인쇄는 100% Xprinter로만 핀포인트 전송됩니다. 일반 문서 인쇄 시 A4 복합기 출력에 아무런 영향을 주지 않습니다.
3. **초경량 백그라운드 구동**: 윈도우 .NET Framework 내장 기능으로 작동하여 CPU 점유율 0%, 메모리 10MB 미만으로 윈도우 시계 옆 트레이에서 상시 대기합니다.
4. **자동 복구 및 안전 전환**: 브릿지 프로그램이 꺼져 있거나 외부 PC(대표님 노트북 등)에서 접속할 경우, 기존 웹 브라우저 인쇄 모드로 자동 전환됩니다.

## 파일 구성
- `ChoicommaPrintBridge.exe` : 실행 파일 (더블 클릭 시 트레이 아이콘으로 실행)
- `ChoicommaPrintBridge.cs` : C# 원본 소스 코드
- `build.bat` / `build.ps1` : 소스 수정 시 즉시 재컴파일하는 빌더
- `install-startup.bat` : 윈도우 시작프로그램 1클릭 등록기 (PC 부팅 시 자동 실행)
- `start.bat` : 프로그램 실행 스크립트
- `stop.bat` : 프로그램 종료 스크립트

## 시작프로그램 등록 방법
`install-startup.bat`을 한 번만 실행하면 윈도우 시작 시 자동으로 실행됩니다.
(윈도우 시계 옆 트레이에 프린터 모양 아이콘이 표시됩니다.)
